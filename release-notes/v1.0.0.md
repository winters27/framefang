The first Framefang release: a pure Rust screenshot tool for Windows.

## Install

Download **Framefang.msi** below and run it. Framefang starts in the tray. Press **Print Screen** to capture.

Windows 11 sends Print Screen to the Snipping Tool by default. Open Framefang's Settings and use the button under Hotkeys to hand the key over.

Screen recording and video conversion use FFmpeg, which is not bundled. Install it once if you want them: `winget install Gyan.FFmpeg`.

## Highlights

- **Freeze and pick:** the screen freezes the moment you press the key, then the picture opens in a small editor right where it was, with the rest of the desktop live around it.
- **Move it, then mark it up:** the editor opens with no tool picked, so dragging the picture moves it. Pick a tool to draw; pick it again or press Esc to put it down.
- **Tools that remember:** pen, line, arrow, box, circle, highlighter, text, numbered steps and pixelate, each with its own size and color in a flyout beside its button.
- **Copy, save or pin:** copy to the clipboard (optionally on every capture), save to a folder, or pin the picture on top.
- **Color schemes:** Pink, Green, Cyan or Yellow for the app's windows.
- **A dependable capture key:** Print Screen is also heard through raw keyboard input, so apps that swallow hotkeys no longer block it.

## Files

- `Framefang.msi`: the installer.
- `framefang-windows-x86_64.zip`: portable, just `framefang.exe`.
- `SHA256SUMS`: checksums the in-app updater verifies before installing.
