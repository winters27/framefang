Settings save themselves, a new Orange theme, a cleaner black look, and Esc reliably closes the capture screen.

## New

- **Orange theme.** A fifth color scheme in Settings > Appearance.
- **No Save button.** Every change in Settings saves and takes effect the moment you make it. Close the window with Esc or its close button. New shortcut keys start working when Settings closes, since shortcuts are paused while it's open so you can press keys to rebind them.
- **Reset marks.** A small diamond in your theme color appears beside any setting that isn't at its default. Point at it to see "Reset to default", click it to put that one setting back.
- **Import and export your settings.** Export... saves a copy of your settings as a JSON file wherever you like. Import... loads one, and tells you what's wrong with a file that isn't Frame Fang settings instead of loading it.
- **Edit settings.json directly.** Changes you save to `settings.json` (Edit as JSON in Settings opens it) take effect within a second, even with Settings open. A typo changes nothing and you get a notice naming the line. The tray menu's Sound choice is now kept there too.
- **`framefang --settings`** opens Settings, in the copy that's already running if there is one.

## Changed

- **Pure black background.** Settings, the tray menu and the other windows drop their scanlines for a flat black background.
- **Easier-to-read Settings.** Section headings are bigger, with more room above and below them.
- **Quitting is clearly quitting.** The tray menu's Exit sat where a "close menu" button would, and quit the whole app. It now reads `> KILL FRAME_FANG` and lights up with a blinking cursor when you point at it. To close just the menu, click anywhere else or press Esc. On macOS and Linux the menu says **Quit Frame Fang**.

## Fixed

- **Start with system works.** The setting was saved but never acted on, on any platform. Turning it on now adds Frame Fang to your startup apps (Windows), a login item (macOS) or your desktop's autostart (Linux); turning it off removes it.
- **Esc closes the capture screen every time (Windows).** Windows sometimes kept the keyboard on the window behind the frozen screen, so Esc went there and the capture screen stayed up. It now takes the keyboard back, and closes on Esc even while another window has it. The same goes for picking an area to record and for the color picker.
- **A settings file with a mistake is kept.** If `settings.json` can't be read at startup, Frame Fang starts with the defaults and keeps your file as `settings.broken.json` instead of overwriting it.
- **The capture editor no longer undoes Settings changes.** Adjusting a tool in an editor that was open before you changed a setting used to write the old value back.

## Updating

From 1.4.0 or later, use **Check for updates** in the tray and press **Update now**: Frame Fang downloads, installs and reopens by itself.

From 1.3.0 or earlier, your copy still has the old updater, so this update goes the old way once: use **Check for updates** and follow the installer, or download `Framefang.msi` below and run it.

## Files

- `Framefang.msi`: the Windows installer.
- `Framefang-portable.exe`: Windows, runs without installing.
- `Framefang-macos-arm64.dmg`: macOS on Apple silicon (M1 and later).
- `Framefang-macos-x64.dmg`: macOS on Intel.
- `Framefang-linux-x86_64.AppImage`: Linux, one file. Make it executable, then run it.
- `Framefang-linux-x86_64-portable.tar.gz` and `Framefang-linux-arm64-portable.tar.gz`: Linux, the bare app.
- `SHA256SUMS`: checksums the in-app updater verifies.

The Mac app isn't signed by Apple yet. The first time you open it, macOS blocks it: go to **System Settings > Privacy & Security** and click **Open Anyway**.
