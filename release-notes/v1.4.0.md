A real one-click updater, and Framefang now comes for macOS and Linux too.

## New

- **Update now.** Checking for updates is one button: Framefang downloads the new version, checks it against the published checksum, installs it and opens again by itself. The dialog shows the download's progress, and if anything goes wrong it says why and offers Try again. Windows asks for permission once, since Framefang is installed in Program Files.
- **No more flashing windows.** Checking for updates no longer flashes command prompt windows.
- **The portable version updates itself** too, instead of sending you to the browser.
- **macOS and Linux.** Each release now has a Mac app for Apple silicon and Intel, and a Linux AppImage plus portable builds for x86_64 and ARM. These are new: they build and pass their tests, but haven't had much use on real machines yet, so reports are very welcome.

## Changed

- Release files are no longer zipped. The Windows portable is now `Framefang-portable.exe`, the app itself.

## Updating from 1.3.0 or earlier

Your current version still has the old updater, so this one update goes the old way: use **Check for updates** in the tray and follow the installer, or download `Framefang.msi` below and run it. From 1.4.0 on, updates are one click.

## Files

- `Framefang.msi`: the Windows installer.
- `Framefang-portable.exe`: Windows, runs without installing.
- `Framefang-macos-arm64.dmg`: macOS on Apple silicon (M1 and later).
- `Framefang-macos-x64.dmg`: macOS on Intel.
- `Framefang-linux-x86_64.AppImage`: Linux, one file. Make it executable, then run it.
- `Framefang-linux-x86_64-portable.tar.gz` and `Framefang-linux-arm64-portable.tar.gz`: Linux, the bare app.
- `SHA256SUMS`: checksums the in-app updater verifies.

The Mac app isn't signed by Apple yet. The first time you open it, macOS blocks it: go to **System Settings > Privacy & Security** and click **Open Anyway**.
