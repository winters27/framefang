A new tray menu on Windows, a sharper tray icon, and no more console windows flashing up.

## New

- **Tray menu in your color scheme (Windows).** Clicking the tray icon opens Frame Fang's own menu, in the same look as Settings and in the color you picked there. Rows show the shortcut keys you set. Delays, sound for recordings and the converters are now chips on one row each, so the menu is shorter. The arrow keys and Enter work in it too.
- **Pick the sound once.** The menu's Sound row (None, Mic, PC, Both) applies to both Record screen and Record region.

## Changed

- **Faster captures from the menu.** A capture started from the Windows tray menu now waits 200 ms instead of 700 ms before taking the screen.
- **Sharper tray icon.** It no longer looks squashed, and it's drawn at the size the taskbar shows it.
- **Clearer tooltip.** Hovering the tray icon shows the capture key you set in Settings.
- **Key names** read the way they're printed on the keyboard: Print Screen, Page Up, Caps Lock.

## Fixed

- Opening your screenshots or recordings folder, or a link, no longer flashes a console window on Windows.
- Cancel pending is gone from the Windows and macOS menus, where it couldn't be reached during a countdown. It stays on Linux, where it works.

macOS and Linux keep their system tray menus.

## Updating

From 1.4.0 or later, use **Check for updates** in the tray and press **Update now**: Frame Fang downloads, installs and reopens by itself.

From 1.3.0 or earlier, your copy still has the old updater, so this update goes the old way once: use **Check for updates** and follow the installer, or download `Framefang.msi` below and run it.

## Files

- `Framefang.msi`: the Windows installer.
- `Framefang-portable.exe`: Windows, runs without installing.
- `Framefang-macos-arm64.dmg`: macOS on Apple silicon (M1 and later).
- `Framefang-macos-x64.dmg`: macOS on Intel.
- `Framefang-linux-x86_64.AppImage`: Linux, one file. Make it executable, then run it.
- `Framefang-linux-x86_64-portable.tar.gz` and `Framefang-linux-arm64-portable.tar.gz`: Linux, the bare app.
- `SHA256SUMS`: checksums the in-app updater verifies.

The Mac app isn't signed by Apple yet. The first time you open it, macOS blocks it: go to **System Settings > Privacy & Security** and click **Open Anyway**.
